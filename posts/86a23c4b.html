CMake 是什么？

CMake 是一个跨平台的构建工具，它不直接编译代码，而是生成 Makefile（或其他构建文件），然后交给 make 去编译。

为什么不用 Makefile 直接写？

  • Makefile 在不同平台（Linux / Windows / macOS）上写法不一样
  • Makefile 处理依赖、库查找、交叉编译很麻烦
  • CMake 用声明式语法，你描述"要编译什么"，它帮你处理细节

CMake 常用变量

CMake 中有很多预定义变量，帮你获取路径、配置编译选项。最常用的列在下面：

路径相关变量

变量 含义 典型值
CMAKE_SOURCE_DIR 顶层源码目录（最顶层的 CMakeLists.txt 所在位置） /home/user/my_project
CMAKE_BINARY_DIR 顶层构建目录（cmake -B 指定的目录） /home/user/my_project/build
CMAKE_CURRENT_SOURCE_DIR 当前 CMakeLists.txt 所在的源码目录 /home/user/my_project/src
CMAKE_CURRENT_BINARY_DIR 当前 CMakeLists.txt 对应的构建目录 /home/user/my_project/build/src
PROJECT_SOURCE_DIR 最近一次 project() 命令所在的源码目录 同 CMAKE_SOURCE_DIR（单项目时）
PROJECT_BINARY_DIR 最近一次 project() 命令对应的构建目录 同 CMAKE_BINARY_DIR

📌 区别：如果你的项目有多个子目录，每个子目录有自己的 CMakeLists.txt，那么 CMAKE_CURRENT_* 指向当前文件所在的位置，而 CMAKE_SOURCE_DIR 始终指向最顶层。

项目信息变量

变量 含义 说明
PROJECT_NAME 项目名称 由 project() 定义
PROJECT_VERSION 项目版本号 由 project(VERSION x.y.z) 定义
PROJECT_DESCRIPTION 项目描述 由 project(DESCRIPTION ...) 定义
CMAKE_PROJECT_NAME 顶层项目名称 即使你在子目录中，它也指向最外层项目名

编译相关变量

变量 含义 说明
CMAKE_BUILD_TYPE 构建类型 Debug / Release / MinSizeRel / RelWithDebInfo
CMAKE_C_COMPILER C 编译器路径 默认是系统 gcc/cc
CMAKE_CXX_COMPILER C++ 编译器路径 默认是系统 g++/c++
CMAKE_C_STANDARD C 语言标准 11 / 17 等
CMAKE_CXX_STANDARD C++ 语言标准 11 / 14 / 17 / 20
CMAKE_CXX_STANDARD_REQUIRED 是否强制使用指定标准 ON 或 OFF
CMAKE_EXPORT_COMPILE_COMMANDS 是否生成 compile_commands.json ON 或 OFF

输出目录变量

变量 含义
CMAKE_RUNTIME_OUTPUT_DIRECTORY 可执行文件输出目录（.exe / 无后缀）
CMAKE_LIBRARY_OUTPUT_DIRECTORY 动态库输出目录（.so / .dylib）
CMAKE_ARCHIVE_OUTPUT_DIRECTORY 静态库输出目录（.a / .lib）

常见错误与解决

Q：添加了新文件，编译时没找到？

A：如果你手动列出源文件，添加后更新 CMakeLists.txt 即可。如果用了 file(GLOB ...)，需要手动重新运行 cmake .. 重新配置。

Q：找不到头文件？

A：检查 target_include_directories() 的路径是否正确，路径相对于 CMakeLists.txt 所在目录。

Q：链接错误 undefined reference？

A：检查 target_link_libraries() 是否都链上了，注意顺序——被依赖的库要放在后面。

命令 作用 常用参数
cmake_minimum_required() 最低版本要求 VERSION x.xx
project() 定义项目 项目名 VERSION x.y LANGUAGES C
add_executable() 创建可执行文件 目标名 源文件...
add_library() 创建库 库名 STATIC/SHARED 源文件...
target_include_directories() 添加头文件路径 目标名 PRIVATE/PUBLIC 路径
target_link_libraries() 链接库 目标名 PRIVATE/PUBLIC 库名
target_compile_options() 添加编译选项 目标名 PRIVATE -Wall -Wextra
target_compile_definitions() 添加宏定义 目标名 PRIVATE 宏名=值
add_subdirectory() 添加子目录 路径
find_package() 查找外部包 包名 REQUIRED
install() 安装规则 TARGETS/FILES DESTINATION 路径
set() 设置变量 变量名 值
option() 开关选项 变量名 描述 ON/OFF
message() 打印消息 STATUS/WARNING/FATAL_ERROR 内容
if()/elseif()/else()/endif() 条件判断 变量 STREQUAL 值
foreach()/endforeach() 循环 变量 RANGE 1 10
function()/endfunction() 自定义函数 函数名 参数...

最后的话：CMake 其实不复杂，记住这几个核心命令就能搞定大部分项目。先动手写一个 hello world，然后逐渐往项目里加功能，边用边学才是最快的上手方式。

遇到不懂的命令？用 cmake --help-command <命令名> 查看官方帮助，比如 cmake --help-command add_executable。
