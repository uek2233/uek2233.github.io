变量 含义
$0 脚本自身路径
$1 $2 ... 第 1/2/... 个参数
$# 参数个数
$@ 所有参数（每个独立加引号）
$* 所有参数（当作一个字符串）
$? 上一条命令退出码（0 成功，非 0 失败）
$$ 当前脚本 PID
$! 最后一个后台进程 PID
$- 当前 shell 的选项标记
$_ 上一条命令的最后一个参数

条件表达式速查

写法 用途
if [[ ... ]] 字符串、文件、正则判断
if (( ... )) 数值运算与比较
if cmd 检查命令退出码
[[ -z "$v" ]] 变量为空
[[ -n "$v" ]] 变量非空
[[ "$a" == "$b" ]] 字符串相等
[[ "$a" =~ regex ]] 正则匹配
(( a > b )) 数值比较
-f -d -e -s -L 文件类型
-r -w -x 文件权限

循环速查

场景 写法
遍历列表 for i in a b c; do ...
遍历数字 for ((i=0; i<n; i++))
遍历文件 for f in *.txt; do
读文件 while read -r line; do ... done < file
无限循环 while true; do ... done
计数器 while (( i < n )); do ((i++)); done
直到条件 until [[ ... ]]; do ... done

字符串操作速查

表达式 含义
${#s} 字符串长度
${s:3:5} 子串（偏移 3，长度 5）
${s#prefix} 删最短前缀
${s##prefix} 删最长前缀
${s%suffix} 删最短后缀
${s%%suffix} 删最长后缀
${s/old/new} 替换第一个
${s//old/new} 替换全部
${s:-default} 默认值

推荐阅读：man bash 中的 SHELL GRAMMAR / PARAMETER EXPANSION / CONDITIONAL EXPRESSIONS 章节。
