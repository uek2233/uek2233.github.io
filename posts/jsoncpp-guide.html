JSONcpp 使用指南

C++ JSON 解析库 — 轻量、高效、易用

什么是 JSONcpp？

JSONcpp 是一个轻量级的 C++ JSON 库，用于解析、构建和序列化 JSON 数据。

特点：

  • 纯 C++ 实现，无外部依赖
  • 支持 STL 风格迭代器
  • 提供美观/压缩两种序列化格式
  • 支持注释（非标准 JSON 扩展）
  • MIT 开源协议

常见坑

  • parseFromStream 传左值 — istringstream 不能传临时对象
  • 中文输出 uXXXX — 内部 UTF-8 编码，渲染时正常显示
  • operator[] 自动创建 key — 只想检查用 isMember()
  • range-for 遍历对象 — 必须用 const auto&
  • asString() 非 string — 不会崩溃但结果不对，要先 isString()
