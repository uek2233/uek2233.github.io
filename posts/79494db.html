Docker 网络

网络模式总览

模式 说明 使用场景
bridge 默认模式，容器间可通信，与宿主机隔离 单机多容器通信
host 容器直接使用宿主机网络栈，无端口映射 高性能需求、网络监控
none 无网络 特殊隔离场景
overlay 跨宿主机网络（Swarm 模式） 多机编排

Dockerfile 基础

Dockerfile 常用指令

指令 作用 要点
FROM 指定基础镜像 尽量用 Alpine / slim 版减小体积
WORKDIR 设置工作目录 相当于 cd，路径不存在会自动创建
COPY 拷贝文件 COPY . . 是拷贝构建上下文到 WORKDIR
ADD 增强版 COPY 支持自动解压 tar、远程 URL（不推荐用 URL）
RUN 在构建时执行命令 每一条 RUN 创建一个新层，尽量合并
ENV 设置环境变量 对后续 RUN / CMD 生效
EXPOSE 声明端口 仅文档用途，不实际映射端口
CMD 启动默认命令 可被 docker run 参数覆盖
ENTRYPOINT 容器入口点 与 CMD 搭配使用，不易被覆盖
ARG 构建参数 docker build --build-arg VERSION=1.0
LABEL 元数据标注 LABEL maintainer="xxx" version="1.0"
HEALTHCHECK 健康检查 告诉 Docker 如何判断容器是否正常
USER 切换用户 安全原则：不要用 root 运行应用

Docker Compose

为什么用 Compose

当你需要多个容器配合运行（比如 Web + MySQL + Redis），手动一个个 docker run 会很麻烦。Compose 用 YAML 文件定义所有服务，一条命令启动全部。

⚠️ 文件名注意： 是 docker-compose.yaml（或 compose.yaml），不是 docker-compose.yam。

类别 命令 说明
镜像 docker pull 拉取镜像
镜像 docker images 查看镜像列表
镜像 docker rmi 删除镜像
镜像 docker build 构建镜像
镜像 docker save / load 镜像备份/恢复
镜像 docker tag 镜像打标签
镜像 docker push 推送镜像
容器 docker run 创建+运行
容器 docker ps 查看运行中的容器
容器 docker start/stop/restart 启停容器
容器 docker rm 删除容器
容器 docker exec 在容器内执行命令
容器 docker logs 查看日志
容器 docker cp 文件拷贝
容器 docker commit 将容器打包为新镜像
网络 docker network create 创建网络
网络 docker network ls 查看网络
网络 docker network connect 连接容器到网络
卷 docker volume create 创建数据卷
卷 docker volume ls 查看数据卷
卷 docker volume inspect 查看数据卷详情
系统 docker system df 查看磁盘占用
系统 docker system prune 清理未使用资源
系统 docker stats 查看实时资源占用
系统 docker info 查看 Docker 系统信息
系统 docker version 查看版本
